## Decisions made by Claude (small, inside the documents)

- F1: Error body built by one global filter; code throws `ApiError(status, code, message, details?)`. Nest's own 404 (unknown route) maps to `NOT_FOUND`, its 400 to `VALIDATION_FAILED`, anything else to `500 INTERNAL_ERROR` (cause logged).
- F1: Prisma client generated by `postinstall` and `build` scripts.
- F2: Prisma creates `text[]` columns as nullable. Migration `array_columns_not_null` sets NOT NULL (DB v0.5). Prisma's diff ignores list nullability, so no drift. Add the same `ALTER ... SET NOT NULL` by hand for any new list column.
- F2: `apps/api/.prettierignore` skips the generated client, so `npm run format` in `apps/api` is safe.
- Apply migrations to Neon `main` by hand before deploying: `npx prisma migrate deploy` with `DIRECT_URL` pointing at `main` (TDD 11). Not done yet.
